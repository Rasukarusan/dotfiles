    操作方法

    クリックdiff行の + ボタンでその行にコメント
    j / k次 / 前のグループへ移動
    cまとめをコピー
    ⌘Enterコメント編集中に保存
    Escコメント編集をキャンセル / コメント一覧を閉じる

    コメントは自動保存されます。 「レビュー完了」で結果がClaudeのセッションへ返ります。送信後も画面はそのまま使え、追加コメントして再送信もできます。 別セッション(Codex等)に投げる場合は「まとめをコピー」を使ってください。
