# eli5

このトピックを何も知らない人に向けて、大きな絵と少ない言葉だけのHTMLで説明する。

トピック: $ARGUMENTS

トピックが空の場合は「このブランチでやっていること」を説明する。
その場合はまず `BASE=$(bash ~/.claude/docs/get-base-branch.sh)` でベースブランチを取得し、
`git diff $BASE...HEAD` とコミットログから変更内容を把握してからHTMLを書く。

## 手順

1. `artifact-design` スキルを読む（レイアウト・配色・デザインの投資量）。
2. `artifact-diagramming` スキルを読む（図をインラインSVGでどう描くか）。
3. 上の2つに従ってHTMLを書く。ただし **単体で開ける完全なHTML** にする
   （`<!doctype html>`・`<head>`・`<style>` を自分で書く。Artifactランタイムの土台は無い）。
4. `open <ファイル名>` でブラウザに表示し、パスを伝える。

## 禁止事項

- **Artifact として公開しない。** `Artifact` ツールを使わず、カレントディレクトリにHTMLファイルとして書き出す。
  公開するかは人間が決める。デザインと図の指針だけを上の2スキルから借りる。
- **ダークモード対応を書かない。** `prefers-color-scheme` も `data-theme` も使わず、
  `color-scheme: light` で固定する。2スキルのテーマ対応の指示はここでは無視する。
