PR のレビュアーに「動くこと」を見せるための動画を撮るスキル。
引数には確認したいシナリオ (例: `ログアウト状態からログインできること`) が渡される。

画面全体を録画するので、**録画中に映って良いのは操作対象のブラウザだけ**。
ターミナルを前面に出した瞬間に台無しになる。ここが一番の失敗ポイント。

## 使う道具

| コマンド | 役割 |
|---|---|
| `rec start` / `rec stop` | 画面録画の開始・停止 (停止時に mp4 へ圧縮して Finder で表示) |
| `caption "テキスト"` | 画面下部中央に字幕を表示・更新 |
| `caption --hide` | 字幕を消す |
| `mcp__claude-in-chrome__*` | ブラウザ操作 |

`rec` / `caption` は `~/dotfiles/bin` にある。無ければ
`bash ~/dotfiles/bin/claude-caption/build.sh` でビルドする。

## 手順

### 1. シナリオを組み立てて承認を得る

引数と、ブランチの差分 (`git log --oneline $(git merge-base master HEAD)..HEAD`、PR があれば
`gh pr view`) から、**何を見せれば「動いている」と信じてもらえるか**を決める。

台本は「字幕 → 操作」の組で書く。ステップは 4〜8 個が目安。多いと動画が長くなり、
PR に貼れるサイズ (10MB) を超える。

台本をユーザーに提示し、あわせて次を伝えてから承認を得る。

- 録画中は画面全体が録られるので、**マウス・キーボードに触らないでほしい**こと
- 想定の所要時間

**承認前に録画を始めない。** 撮り直しはユーザーの時間を奪う。

### 2. 初期状態を作る (録画前)

録画を始める前に、ブラウザを「動画の1コマ目」の状態にしておく。

- 対象 URL が生きているか確認する (`curl -sS -o /dev/null -w '%{http_code}' <URL>`)。
  落ちていればユーザーに起動を依頼して止まる。dev サーバーを勝手に起動しない
- タブを開き、ログイン状態などの前提を整える
- ページの読み込み・リダイレクトが完全に終わるまで待つ

準備の過程は動画に入れない。ここで整えておくほど動画が短くなる。

### 3. ブラウザを前面に出す

```bash
open -a "Google Chrome"
```

以降、録画が終わるまでターミナルやエディタを前面に出さない。
Bash や MCP のツール呼び出しはフォーカスを奪わないので、そのまま操作を続けてよい。

### 4. 録画する

```bash
rec start
```

各ステップは必ず **字幕を出してから操作する**。順序が逆だと、レビュアーは
何が起きたか分からないまま画面が変わるのを見ることになる。

```bash
caption "① ログアウト状態のトップページです"
# 3秒待つ → 操作 → 結果が描画されるまで待つ
caption "② ログインボタンを押します"
```

守ること。

- **字幕は最低 3 秒表示する。** 日本語 1 文を読むのに要る時間。長い文はもっと待つ
- **操作の結果が画面に出きるまで待ってから次の字幕に進む。** 遷移中に字幕が変わると
  どの説明がどの画面のものか分からなくなる
- **字幕は画面の説明に徹する。** 「〜を押します」「〜が表示されました」のように、
  レビュアーが見ている画面と 1 対 1 で対応させる。実装の解説は PR 本文の仕事
- 番号 (①②③) を振ると進行が追いやすい

最後のステップの結果を 3 秒見せてから終える。

```bash
caption --hide
rec stop
```

### 5. 確認して報告する

**撮って出しで報告しない。** `ffmpeg` でフレームを抜き、字幕と画面が意図通りかを自分の目で見る。

```bash
ffmpeg -y -loglevel error -ss <秒> -i <mp4> -frames:v 1 -vf scale=900:-1 <出力png>
```

各ステップの真ん中あたりのフレームを確認する。破綻していれば撮り直す
(字幕が切れている・遷移中のフレームばかり・意図した画面が出ていない、など)。

報告するのは、mp4 のパス・長さ・サイズ・各ステップの字幕。
10MB を超えていたらステップを削るか短くして撮り直す。

## やらないこと

- **音声を入れない。** 無音の字幕付き動画で完結させる
- **失敗した録画を残さない。** 撮り直すときは `rec abort` で破棄する
- **動画をどこかにアップロードしない。** PR への添付は人間が判断する
