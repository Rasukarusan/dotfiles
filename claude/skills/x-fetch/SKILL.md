---

x.com は WebFetch をボットとして弾くため、fxtwitter API 経由で取得するスクリプトを使う。

## 取得

URL ごとに次を実行する (URL はクォートする。`?` が zsh のグロブになるため)。複数あれば並列で実行する。

```bash
~/.claude/skills/x-fetch/scripts/fetch.py '<URL>'
```

標準出力に Markdown が出る。中身は次のとおり。

- ポスト: 本人の連投 (最大 50 件) を先頭から順に。指定した URL のポストには「（指定ポスト）」が付く
- 各ポストの本文・投稿者・日時・画像/動画 URL・引用ポスト・コミュニティノート
- 記事 (`/i/article/`): タイトルと本文

他人のリプライは取得できない。必要なら取得できない旨を伝える。

## 失敗したとき

- 終了コード 2: X の URL ではない。通常の WebFetch で読む
- 終了コード 1: 削除・非公開・API 障害。取得できなかったことをそのまま伝え、本文を推測で補わない
- 見出しに「oEmbed」と出たら長文が途中で切れている。そのことを添えて伝える

## 出力

ユーザーの依頼 (要約・翻訳・全文表示など) に合わせて整える。依頼が URL だけなら、スレッドの要点を短くまとめ、元 URL を添える。画像の内容が必要なら画像 URL を curl で scratchpad に保存して Read で見る。
