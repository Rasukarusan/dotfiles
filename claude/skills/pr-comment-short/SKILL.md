この会話でやったこと（引数があればその内容）を、PR コメントにそのまま貼れる短い文面に Markdown でまとめ、` ```markdown ` のコードブロックに入れて出す。

- 2〜5 行程度。箇条書きか 1〜2 文のどちらか短く済む方にする。
- 何をしたか・結果だけを書く。経緯・調査の過程・感想・挨拶・見出しは入れない。
- 文末は「〜しました」などの敬体にする。
- ファイル名・関数名などはバッククォートで囲む。
- 投稿はしない。文面を出すだけにする。
