# やること
今のブランチのPRのレビューコメント一覧を取得し、そのまま提示する。

## 取得方法
必ず次のコマンドを使うこと（`gh` を自分で組み立てない）。

```shell
pr-comments
```

実体は `~/dotfiles/bin/pr-comments`。tmux の prefix+* で右上ペインに表示される一覧と同じ実装なので、
ここで出す番号(#N)と右上ペインの番号は必ず一致する。

## 除外条件（スクリプト側で適用済み）
- 解決済み(Resolved)になっているスレッド
- eslint など bot のコメント
- スレッドの最初または最後がレビュイー(PR作者)のコメント

## 出力について
- スクリプトの出力をまとめず、そのまま出力すること
- 番号(#N)はスクリプトが振ったものを使い、振り直さないこと
